# Bundled fonts

| File | Font | Licence |
|---|---|---|
| Inter-*.ttf | Inter 4.1 by Rasmus Andersson | SIL OFL 1.1 (`LICENSE-Inter.txt`) |
| NotoSerif-*.ttf | Noto Serif | SIL OFL 1.1 (`LICENSE-Noto.txt`) |
| JetBrainsMono-Regular.ttf | JetBrains Mono | SIL OFL 1.1 (`LICENSE-JetBrainsMono.txt`) |

The Inter files have their Private Use Area cmap entries (U+E000–U+F8FF) removed so they
don't shadow the Phosphor icon font, which lives in the same range. Nothing else is changed.
